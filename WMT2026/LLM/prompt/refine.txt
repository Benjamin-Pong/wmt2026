
You are an annotator for the quality of machine translation. Your task is to reflect on the predicted
error spans produced by an autorater given the following source and target segments, 
and re-segment and/or re-classify these spans in terms of their severity of errors should they be incorrect
```source:{source_language}``` \n
```source segment: {source_segment}```\n
```target language: {target_language}```\n
```machine translation: {target_segment}```\n
```predicted error spans: {xcomet_error_spans}```

\n

#### Guidelines and Error Taxonomy ######
The categories of errors are: accuracy
(addition, mistranslation, omission, untranslated text), fluency (character encoding, grammar,
inconsistency, punctuation, register, spelling),
locale convention (currency, date, name, telephone, or time format)
style (awkward), terminology (inappropriate for context, inconsistent use), non-translation,
other, or no-error.\n

Each error is classified as one of two categories: major, minor.
Critical errors inhibit comprehension of the text. Major errors disrupt the flow, but what
the text is trying to say is still understandable. Minor errors are technically errors,
but do not disrupt the flow or hinder comprehension. \n

### Your task #######
Make sure to only evaluate the given error spans given the machine translation in {target_language}, and the source segment in {source_language}.

Think step-by-step:
1. For each entry in the predicted spas, evaluyated the translated text identified by the autorater as a mistranslation, and whether it is a true mistranslation error. 
2. If this is a true error and its severity has been misclassified, reclassify its severity. 
3. If the span is not a true error, meaning no mistranslations at all, remove its json entry from the predicted span array.
4. If the span is too long and needs to be resegmented into additional error spans, ensure that the newly segmented entries follow the same format containing only the following keys with the associated values of the following types {{'start': int, 'end':int, 'severity':str}}


Produce a JSON array of objects, similar to the input error spans. Each object represents a single error and
must have exactly these keys: "text", "start", "end", "severity". start' and 'end' are character indices of the identified error span from the target language translation, 'text' is the corresponding text bouded by the start and end indices and "severity" is one of
 "major", or "minor". If none of them are errors, return an empty array [].
You MUST only output the JSON array, with no other text.
